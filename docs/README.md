# Documentation index

Project documentation is organized by the engineering stage in which it is created.

- `00-project/` — baseline, workflow, and project-level conventions.
- `01-requirements/` — functional and non-functional requirements (Phase 1).
- `02-domain/` — glossary and domain model (Phase 2).
- `03-architecture/` — architecture and architecture decision records (Phase 3 onward).
- `04-design/` — detailed component and API design.
- `05-uml/` — context, component, class, sequence, and state diagrams.
- `06-development/` — setup, testing, and contribution guidance.

Directories for later phases will be added when those phases begin; their presence is not a claim that the documents already exist.
